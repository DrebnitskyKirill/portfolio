# Resume Site

Static, single-page resume/portfolio template in Russian. Lightweight, responsive, accessible, with theme toggle and scroll animations.

## Local preview

Using Python HTTP server:

```bash
python3 -m http.server 4321 --directory /workspace/resume-site
```

Then open http://localhost:4321 in your browser.

## Customize

- Edit `index.html` sections: About, Experience, Projects, Writing, Contact
- Replace `assets/avatar.svg` and `assets/favicon.svg`
- Update social links and email
- Adjust colors/spacing in `styles.css`

## Notes

This project is original and does not copy third-party content. Use it as a starting point and tailor it to your profile.
